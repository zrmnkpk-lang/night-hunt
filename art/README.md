# 夜猎庄园美术资产库

本轮覆盖现有三维资产的全部主要类别，共 **18 项可检视/导出的资产**。以 `docs/art-reference/` 中已有图像和已接入的程序化模型为基础，保持简化低多边形方向。当前模型是可用的游戏原型美术，不是写实角色或完整骨骼动画资产。

## 查看

- 游戏：启动 `npm run dev` 后访问 `http://127.0.0.1:3000/`。
- 逐项检视：`http://127.0.0.1:3000/art-review`，可旋转、缩放、切换棚拍/夜景光，检查角色的六种姿态。
- Blender：打开 [night-hunt-art-library.blend](night-hunt-art-library.blend)，场景 `Night_Hunt_Art_Library` 包含 18 个独立命名的资产集合与单独的展示舞台。
- 总览：[asset-library.png](previews/asset-library.png)。

## 文件和权威来源

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 游戏模型生成器 | `../src/game/art.ts`、`characters.ts`、`world.ts` | 当前游戏直接使用这些生成器 |
| 资产目录 | `../src/game/artCatalog.ts` | 检视页和导出共用同一套游戏构造函数 |
| 交换模型 | `models/*.glb` | 18 个单独文件，约 1.1 MB；没有外部贴图依赖 |
| 编辑文件 | `night-hunt-art-library.blend` | 从相同 GLB 导入，保留父子层级、材质和命名旋转轴 |
| 规格清单 | `manifest.json` | 每项资产的面数、网格数、文件大小和坐标约定 |

**GLB 和 Blender 文件目前是编辑/交换交付，游戏继续直接使用优化后的程序化几何。** 修改 Blender 文件不会自动回写 TypeScript；如继续在 Blender 精修，需要另做加载接入。当前不重复下载相同模型，也不新增开局异步加载等待。

## 已落实的优化

- 求生者：连帽结构、抽绳、口袋、袖口、橄榄色斜挎包与金属扣、发束、鞋底鞋带，保留四人服装换色。
- 猎人：面具通气孔和铆钉、翻领、开衩破损衣摆、腰带、手套、尖刃。刀改为手臂子节点，跟随肩部动作，并绕握持点挥动。
- 灯笼：发光核心、火焰、金属底座，保留原来的灯光强度和闪烁逻辑。
- 密码机：倒角外壳、控制键、通风槽、表盘、紧固件、底座；保留转轮和红绿状态材质。
- 椅子：深红软垫、钉扣、黄铜扶手与火箭箍；修复透视高亮的局部坐标。
- 逃生门/开关：铰链板、通风槽、状态面板；门把手与主灯共用通电状态颜色。
- 木板：端部倒角、裂纹、斜撑和铁箍，竖立与倒下共用同一资产；破坏后显示低矮碎木，原碰撞清除流程不变。
- 墙体：低面数倒角、石色变化、压顶、底部苔色、木柱铁箍；低墙改为三列石块与木梁结构。
- 地表/自然：实例化灰绿石板、折枝和外露树根、草丛静态合并、贴地接触阴影。
- 氛围/特效：庄园远景、冷色夜雾、月光阴影、分离的瞬移光带与双环；保留已有攻击扇形提示。

## Blender 编辑约定

- GLB 坐标：米，Y 向上，角色正面 +Z。Blender 导入会转换为 Z 向上。
- 每个 `ASSET_*` 空物体的 `display_scale` 用于总览展示；导出前恢复该锚点缩放为 1，并将位置归零，才能保持游戏尺寸。
- 手臂、腿、头部、武器、门扇与木板旋转轴是刚性父子层级。**未制作 Armature、蒙皮或烘焙动画剪辑**；动作继续由游戏实时计算。
- `00_REVIEW_STAGE` 中的底台、文字、灯光和相机只用于展示，不应导出到游戏。
- 参考图继续保留在 `docs/art-reference/`，不作为贴图绑定。

## 重建与验证

```powershell
npm run art:export
npm run art:verify
npm run build
& 'D:\blender\blender.exe' --background --python scripts/build-blender-library.py
```

若使用本机 Blender MCP，当前脚本执行目录仅允许 `D:\blender`：将制作脚本复制到该目录，以 `args.project_root = 'D:/aiproject/night-hunt'` 执行。脚本只重建带有 `generated_by=night-hunt-art` 标记的资产场景。

`art:verify` 与优化前版本 `f1e37081ad585c0c947b1a66fc789e546b159586` 的原始世界构造器比较碰撞和视线数据；可通过 `NIGHT_HUNT_ART_BASELINE` 环境变量指定其他基准。报告位于 [verification.json](previews/verification.json)。

静态场景可见网格约从 1,315 降至 663；三角面约从 1.8 万增加到 11.3 万（包含 900 个地砖实例）。这是细节与绘制批次的取舍，不是帧率提升承诺。月光新增一张 2048 阴影贴图。

已验证：18 个 GLB 结构、全部墙体碰撞/视线数据、5 块木板倒下和破碎状态、两扇门的铰链与通电材质、密码机转轮/完成状态、角色姿态复位、武器父子关系、两种阵营开局/暂停、Blender 导入与总览渲染。

浏览器检视页未发现控制台错误。内置浏览器游戏页存在原有的 `WrongDocumentError` 指针锁定限制，因此鼠标锁定视角尚需在独立浏览器手动复核。修改文件的 lint 检查仅命中 `engine.ts` 中改动前已有的未使用参数 `_c`；构建通过，仍有原有的大包提示。

## 保留和后续范围

现有菜单背景、HUD 图标和 Web Audio 音效继续使用；本轮未重做二维 UI 或制作录制音频。庄园是不可进入的远景轮廓；骨骼绑定、写实贴图、角色头像和完整音效包仍属后续制作范围。
