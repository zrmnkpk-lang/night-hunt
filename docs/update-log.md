# 《夜猎庄园》项目更新日志

## 2026-09-11

### 三维美术资产统一优化与 Blender 交付

- 基于现有参考和已完成的低模结构，优化角色、灯笼、密码机、椅子、门、木板、墙体、路灯、树木、草丛、地面与瞬移特效；新增庄园远景。
- 保留碰撞、寻路和任务布置；修复握刀父子关系、角色姿态复位和椅子透视高亮偏移。

- 新增 `art:export`、`art:verify`；构建与状态检查通过。范围、限制和验证详情见 [美术交付说明](../art/README.md)。

## 2026-08-30

### 新增杀手可玩角色

- 首页增加求生者/杀手角色选择。
- 增加杀手移动、攻击、瞬移、扛起、破板和翻窗操作。
- 增加杀手专属 HUD，包括淘汰计数、技能冷却和情报小地图。
- 增加按角色区分的胜负判定。
- 修复猎灯缺失、AI 名称为空和扛人状态死锁等问题。
- 新增主菜单背景图资源。

对应提交：[20bdd5b](https://github.com/zrmnkpk-lang/night-hunt/commit/20bdd5b71b9ff19782b59ab911760d051f8d82e9)

### 增加攻击命中后的硬直

- 杀手命中求生者后进入约 2 秒攻击恢复状态。
- 硬直期间禁止再次攻击、瞬移、扛起、破板和翻窗。
- HUD 增加“攻击恢复中”提示和读条。
- 攻击落空仍使用较短的普通后摇。

对应提交：[31bd51c](https://github.com/zrmnkpk-lang/night-hunt/commit/31bd51c03fec79a9d987b63946b8a44e69c3dfe0)

## 2026-08-12

### 完成基础游戏框架

- 建立 Three.js 非对称对抗游戏基础玩法。
- 加入监管者 AI，包括 A* 寻路、预测拦截、动态寻路和瞬移技能。
- 加入求生者 AI，包括破译、治疗、救援、逃脱和冲刺技能。
- 建立碰撞系统、密码机、狂欢之椅、上椅三阶段和观战模式。
- 增加性能优化、难度设置、灵敏度设置、音量设置和 localStorage 持久化。
