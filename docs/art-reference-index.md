# 《夜猎庄园》美术参考图索引

> 更新日期：2026-09-10  
> 范围：与仓库现有 Three.js 程序化资产相对应的视觉参考图。图片已按用途归档至 `docs/art-reference/`，用于后续模型、材质与场景迭代时统一风格。

## 使用约定

- 2026-09-11：这些参考方向已用于优化游戏内主要三维资产。查看 [美术资产库](../art/README.md) 中的落地细节、导出文件与检视方法；下文“未接入”指参考图文件本身没有作为游戏贴图加载。

- 这些文件是**美术参考**，尚未接入运行时代码；当前游戏仍使用程序化低多边形模型。
- 同一资产有多个版本时，将其作为候选方向保留，落地建模前再选定最终版本。
- 参考图按「角色」「交互物」「环境」组织；具体对应到现有资产清单的章节见下表。
