## 5. UI、动效与音频

- 主菜单、阵营选择、操作说明、暂停页、结算页：React + Tailwind CSS
- 小地图、QTE 表盘、技能图标：内联 SVG
- 受伤暗角、危险提示、Toast、进度条、冷却遮罩：CSS 与 React 状态驱动
- 环境风声、心跳、追击、密码机、QTE 和事件提示音：Web Audio 实时合成

代码位置：`src/components/Hud.tsx`、`src/game/audio.ts`
