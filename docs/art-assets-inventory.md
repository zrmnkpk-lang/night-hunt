# 《夜猎庄园》美术资产清单

> 更新日期：2026-09-10  
> 盘点范围：仓库 `main` 分支当前代码与资源文件。  
> 说明：项目目前以 Three.js 程序化低多边形模型为主。除菜单背景外，绝大多数资产并非独立模型或贴图文件，而是运行时由代码生成。

## 1. 资产概览

| 类别 | 独立文件 | 程序化资产 | 备注 |
| --- | ---: | ---: | --- |
| 位图/背景 | 1 | - | 主菜单背景图 |
| 角色模型 | 0 | 2 类 | 猎人、求生者基础模型 |
| 场景与道具 | 0 | 11 类 | 地图、交互物、植被、灯光等 |
| UI 图形 | 0 | 3 类 | SVG 与 CSS 绘制 |
| 音频文件 | 0 | 1 套 | Web Audio 实时合成 |

当前仓库未包含 `.glb`、`.gltf`、`.fbx`、`.obj` 等三维模型文件，也未包含贴图包、天空盒、独立 UI 图标包或 `.mp3/.wav/.ogg` 音频文件。

## 3. 角色资产

| 资产 | 视觉构成 | 运行时数量 | 状态 |
| --- | --- | ---: | --- |
| 猎人 | 黑色斗篷、白色面具、黑眼洞、长刀、棕靴；玩家操控时附带照明 | 1 | 程序化低多边形模型 |
| 求生者 | 毛衣、头发、面部、裤子、鞋、斜挎包、手提灯笼 | 4 | 同一基础模型，以毛衣颜色区分 |
| 求生者灯笼 | 金属框、暖色发光核心、点光源 | 每名求生者 1 个 | 程序化子模型 |
| 透视轮廓 | 红色半透明轮廓 | 按机制显示 | 材质与重复网格效果 |

角色支持站立、行走、受伤、倒地爬行、被扛、上椅等程序动画；当前没有骨骼、动画文件或角色贴图。

**代码位置：** `src/game/characters.ts`

## 6. 音频资产

项目没有预制音频文件。环境风声、心跳、追击、密码机、QTE 与事件提示音均由 Web Audio 在浏览器内实时生成。

**代码位置：** `src/game/audio.ts`

## 7. 后续美术补充优先级

1. **角色包**：猎人与求生者的独立模型、角色差异化轮廓、基础动作与受击动作。
2. **庄园场景包**：主建筑外立面、地面/墙体材质、石材与木材贴图、围栏、雕像、墓碑等叙事物件。
3. **交互物升级**：密码机、狂欢之椅、电闸门、木板的统一风格化模型与状态材质。
4. **环境氛围包**：植被变体、地表细节、雾粒子、天空盒、月光投影与远景。
5. **UI 与音效包**：可复用图标集、角色头像、状态图标、环境/交互/战斗音效。
